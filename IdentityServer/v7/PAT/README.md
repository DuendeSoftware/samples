# PAT Sample

This sample demonstrates how to generate a Personal Access Token (PAT) for a user with specific scopes.

## How to Run this Sample

1. Run the Aspire project.
1. Navigate to `https://localhost:5001/pat`.
1. Create a PAT with both `API 1` and `API 2` scopes.
1. Copy/Paste the PAT into the `generated-pat` Aspire parameter.
1. The `client` project will automatically run. View its console output to see the token it received.

See the [documentation](https://docs.duendesoftware.com/identityserver/fundamentals/resources) for more information.
