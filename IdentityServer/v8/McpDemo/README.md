# MCP Sample

This sample demonstrates a console client registering itself with IdentityServer and making a call to a locally hosted MCP Server. It uses Dynamic Client Registration (DCR) to allow clients to register at runtime. This sample has more documentation at https://docs.duendesoftware.com/identityserver/quickstarts/8-mcp

## Running the solution

1. Run the Aspire project.
1. The `McpDemo.Client` application runs automatically and opens a browser for you to sign in.
1. Sign in with username `bob` and password `bob`.
1. View the console output for the `mcpdemo-client` application in Aspire, notice it made a call to the MCP Server.
