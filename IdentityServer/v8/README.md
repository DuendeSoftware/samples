# Samples for Duende IdentityServer v7.x

See [here](https://docs.duendesoftware.com/identityserver/samples) for an overview and descriptions

The samples previously using Bootstrap 4 now vendor the official
[Bootstrap 5.3.8 distribution](https://github.com/twbs/bootstrap/releases/tag/v5.3.8)
under `wwwroot/lib/bootstrap`. Each keeps its existing CSS/JavaScript file set,
including minified files and source maps. No package manager is required.
Their UI uses Bootstrap 5 markup and the JavaScript bundle includes Popper;
jQuery and jQuery Validation remain available for samples that use them.
